# Recovered dash motion

This is a standalone controller generated by Muse Wonder 1.0 and repaired by Muse Spark 1.3 from the compiled Dashy Dango cartridge. The source and generated JavaScript are preserved as evaluated. The host selected the boundary, mapped state, supplied binary/development evidence, and authored the evaluator. No original donor source was supplied to Meta and no manual source repair was applied.

The accepted version passed 12 development traces, 21 regression traces, and 20 fresh acceptance traces: 6,744 ticks with zero measured position error and exact dash start/end and motion-ownership timing. The acceptance tolerance was fixed at 0.25 source pixels. These finite checks cover default configuration and source body width 8; they do not establish full-game equivalence or behavior for modified configurations.

The recorded history retains the incomplete first generation and the second candidate's failed acceptance. Those failed acceptance inputs became regressions before a focused patch; acceptance used a fresh seed afterward. Combined estimated generation cost was $0.28511425 across three requests. Source, build, evidence, and evaluations have matching hashes in [provenance.json](provenance.json).

```js
import { init, step } from './component.js';
const config = { walkingSpeed: 2, dashDistance: 60, cooldownTicks: 25, initialCooldownTicks: 10 };
let state = init(config);
// Call once per fixed 60 Hz simulation tick.
const result = step(state, { buttons: 33, sourceBodyWidth: 8 }, config);
state = result.state;
// Apply result.output.displacement; events contain dash-start/dash-end.
```

Input bits are X `1`, left `16`, right `32`, up `64`, down `128`. Combine directions with bitwise OR. `ownsMotion` marks dash ticks; supporting walking is included when false. The recipient should keep its own walking/jumping on those ticks and use the recovered displacement while true. Initial cooldown, held reactivation, frozen active direction, and neutral activation are part of the contract. Combat, score, rendering, and effects are excluded.

`component.js`, `contract.json`, and `package.json` run in a fresh folder without the donor or dependencies. From the repository root, run `npm run verify:motion` to rebuild and replay the saved suites locally without API calls. That command checks the frozen inputs again; it is a regression check, not a new unseen evaluation. Recipient integration is the next stage.
