What was recovered, and what did a human supply?

Meta generated and repaired the movement controller. A human selected the component boundary, mapped runtime fields, supplied code slices and development evidence, and authored the evaluator, recipient adapter and hooks. Dashy Dango's source was withheld from recovery; it was not lost. Visual trails, combat and scoring are outside the component.

The current package uses the previously accepted component. Later exploratory investigations are separate and do not establish a new independent recovery. These finite checks do not prove full-game equivalence or compatibility with arbitrary binaries.
