Pinned from [abagames/agentic-gamedev-games](https://github.com/abagames/agentic-gamedev-games/tree/f30b52a1707282b1559f7bae1fc301925612f5a6/docs/parallaxia), revision `f30b52a1707282b1559f7bae1fc301925612f5a6`, under its MIT license. Upstream bytes and file hashes are preserved in `upstream/` and `recipient.lock.json`.

PARALLAXIA is Kenta Cho / ABA Games' modern browser remake of PARSEC47 (ABA Games, 2003). Its simulation runs at a fixed 60 Hz in both Node and the browser with no external game engine, using 8-way ship movement, swept segment bullet collision, lock-on lasers, and 3 scoring modes (`CHAIN`, `CLOSE`, `GRAZE`). The game, enemy flight patterns, barrages, 2D Canvas renderer, and 5-channel chiptune audio are upstream work by Kenta Cho / ABA Games. Our integration adds separately authored host hooks and an adapter around the unchanged recovered Dashy Dango dash.
