# Dashy Dango → RDSTR Stunts

The same frozen component used in PAKU PAKU and JUJUMP now controls an airborne horizontal burst in [sebayaki's MIT-licensed RDSTR Stunts](../../recipients/roadster/README.md). The upstream car, graphics, audio, controls, stunts and native physics are credited upstream work. Our contribution is the recovered ability, transfer port, Meta adapter generation, verification, guided comparison and live investigation.

`current.json` selects an immutable `versions/<id>/` package with the untouched Meta TypeScript, generated JavaScript, standalone isolated HTML, generation receipt, verification and notices. The original component ID remains `1bc4250c3ca3c1e9a59849d0fd1335e9f7a02a95184d7d51fd6ac678d83226a2`. The host is human-written; the adapter is generated by Muse Spark 1.3. No hand edits were made to its source.

The native game has a 3D renderer and a planar stunt simulation. World X follows the jump path; Y is up. The 60 Hz component is stepped once per four native 240 Hz substeps, with its original configuration and body width 8. Default scale is 0.1 meters per source pixel: eight active updates request six meters, with the source's initial readiness, held retrigger and recharge unchanged. Activation is airborne-only. Collision and landing can clip applied movement without resetting the component's timers. Ordinary horizontal velocity continues integrating internally and supplies displacement again after the dash; vertical velocity, rotation, fuel, lift and landing remain native. This is an arcade software transfer, not a physical vehicle modification.

Active movement sweeps the combined horizontal/vertical path through the existing collision rules with samples at most 0.02 meters apart. Eight independent mapping cases include grounded activation, raw fresh-press consumption, landing during dash, facing and counterfactual component outputs. Seven real-browser checks cover baseline agreement, measured air motion, grounding, declared thin-wall contact, display-rate independence, restart and mobile layout. Finite fixtures do not establish universal program equivalence.

The initial model attempt failed the declared input mapping and cost an estimated $0.00780375. The second cost $0.0093035 and passed conformance. A host bundler initially rejected its valid TypeScript; the loader was fixed and that exact source was re-verified locally without another model request. Earlier artifacts and recorded errors are retained.

The guided demo records native controls from the original simulation, plays the same controls in the transferred one, and slows eight real dash updates. It waits until the car clears the curved ramp; collisions remain enabled. This is saved, scripted execution with no fresh inference. The separate live form submits a new Meta adapter request, retains inherited intent and parent lineage, and publishes only after all checks pass. Earlier PAKU remixes remain separate and usable.

Developer use case: explore a proposed movement mechanic in an existing playable prototype before committing to it. [GDC's rapid iterative prototyping session](https://www.gdcvault.com/play/1016000/Rapid-Iterative-Prototyping-Best) documents the role of experimentation in finding new mechanics. This is a researched use case, not a claim of validated adoption or measured developer time savings.

Run `npm run verify:roadster` to rebuild and recheck the saved Meta adapter without inference. It writes the current result to ignored `reports/roadster-verification.json`. Receipt validation refuses a changed host; after an intentional host change, explicitly re-verify a settled source through `node scripts/recheck-roadster.mjs <run-id> --save` while the preview server is stopped, preserving the same source and accounting history. This local operation uses no API.

Live form validation produced a six-meter backward/fresh-press child and then a three-meter child retaining both changes. Each passed eight mapping and seven browser checks. Their generation costs were $0.008042 and $0.00774575. Actual emitted child playback measured -3 meters across eight updates; parent links and exports remained available. These local artifacts persist in `reports/lab/` across server restarts and require the running server to share.
