What was recovered, and what was built by hand?

Meta reconstructed the standalone dash from selected bytecode and measured donor traces. A human selected the relevant functions, memory watches, and experiment cases. Meta then generated this adapter to call the frozen component inside PAKU PAKU.

The recipient choice, movement and collision hooks, input recording, and verification harness were built by hand. Both versions use the same normalized 60 Hz clock and seed. The adapter maps the original 60-pixel dash to 30 recipient pixels while keeping its timing. Collision contacts retain PAKU PAKU’s dot-then-ghost update order.

This local preview plays a saved, verified transfer. Live remix generation and sharing are the next stage.
