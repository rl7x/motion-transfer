    Adapter · Component · Checks
    What was recovered, and what was built by hand?

    Meta reconstructed the standalone dash from selected bytecode and measured donor traces. A human selected the relevant functions, memory watches, and experiment cases. Meta then generated this adapter to call the frozen component inside PAKU PAKU.

    The recipient choice, movement and collision hooks, input recording, and verification harness were built by hand. Both versions use the same normalized 60 Hz clock and seed. The original transfer maps the 60-pixel dash to 30 recipient pixels while keeping its timing. Collision contacts retain PAKU PAKU’s dot-then-ghost update order.

    Remixes change the adapter’s input mapping or distance scale. Their checks cover the displayed interpretation of the request, preserved recipient play, and unchanged component timers; a changed mapping has its own report. Links persist across local server restarts. Public hosting is still to be built.
